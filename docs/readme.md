# AuditSym sample reports

This directory contains demonstration reports generated by AuditSym using
entirely synthetic organizations, audit data, findings, and evidence.

The reports are provided to demonstrate AuditSym's reporting capabilities,
document structure, executive summaries, methodology, findings, and
evidence presentation.

They do not represent a real organization, audit engagement, certification,
or assurance opinion. Draft samples may contain features or mappings still
under review.
